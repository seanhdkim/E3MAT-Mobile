First Fresnel-zone radius:
r1 = √[(λ × d1 × d2) ÷ (d1 + d2)]

Where λ is wavelength, d1 is transmitter-to-obstruction distance, and d2 is obstruction-to-receiver distance. All distance inputs must use the same units internally; this calculator converts them to meters.
Planning note: Maintaining approximately 60% clearance of the first Fresnel zone is a common planning target for many line-of-sight links. Actual path performance can also be affected by terrain, Earth curvature, antenna heights, multipath, foliage, buildings, weather, polarization, and equipment-specific losses.
